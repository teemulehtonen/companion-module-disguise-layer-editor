# Timeline viewer concept

Open `timeline-viewer.html` in a browser. It is a self-contained, static design preview with fictional data and inline vector thumbnails. No dependencies, network requests, Designer connection or editing functionality are included. The zoom and fit controls are visual placeholders; native scrolling and hover descriptions are available.

The concept shows a focused layer with parameter curves, compact surrounding layers with aggregate keyframe markers, resource thumbnails at change points, and separate timecode, cue and note lanes. Curves are illustrative and do not represent measured Designer interpolation.
